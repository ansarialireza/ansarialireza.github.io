ACTIVE DEVELOPMENT

Weirwise Core

// Lightweight, Modular Open-Source RAG Infrastructure

Weirwise Core is an independent, self-hostable Retrieval-Augmented Generation backend designed to simplify knowledge retrieval for developers. It handles multi-tenant document ingestion, chunking, pgvector similarity search, and conversation management through a clean developer API.

▹ Strict multi-tenant data isolation across knowledge bases, assistants, and queries.
▹ Native PostgreSQL + pgvector retrieval without heavy external vector services.
▹ Asynchronous document ingestion queue for PDF, Markdown, and TXT files.
▹ Dedicated, typed Python SDK (weirwise) with complete integration tests.
Python 3.11+ FastAPI PostgreSQL pgvector Alembic Docker pytest MIT License
